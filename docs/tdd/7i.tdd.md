# 7i: Hero and richer weather card

Source: `tasks/todo.md` PR 7, subtask 7i.

**Journeys**
- As a traveller, I want the city, *region, country* and a one-line description over a full-width photo, so I know the place at a glance.
- As a traveller, I want temperature, feels like, wind, humidity, sunset and a 4-day forecast on the card, so I can plan what to wear.
- As a traveller on a phone, I want the card under the photo; and when the forecast is down, I want current weather only, not an empty row.
