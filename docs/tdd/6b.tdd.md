# 6b — Real writers' map source and wiring

Source: `tasks/todo.md` 6b; `tasks/plan.md` "Search-time matching is a lookup" (point 5).

## Journeys

- As a traveler, I want the map to show real writer pins for my destination, so I see places writers actually mention.
- As a traveler, I want the map to answer quickly from stored results, so no writer site is contacted while I browse.
- As the owner, I want each destination's result recomputed after the monthly sync, so pins follow the index without expiry timers.
- As a designer, I want the Madeira fixture to stay in the preview, so UI work doesn't need a crawl.
