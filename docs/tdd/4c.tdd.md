# 4c — Warm base places from suggestions

Source: [tasks/todo.md](../../tasks/todo.md), PR 4 subtask 4c.

## Journeys

- As a visitor typing a city, I want the top suggestion's base places cached before I select it, so the map can load promptly.
- As a visitor typing repeatedly, I want duplicate queries avoided and at most one new base query per client every two seconds.
- As a visitor when `WRITERS_MAP` is off, I want search suggestions without base queries.

`go test -cover ./internal/adapters/httpserver/...` returned `coverage: 92.1% of statements`. `go test -race ./internal/adapters/httpserver/ -run 'TestSuggestPlaces_|TestSuggestionWarm_' -count=1` returned `ok weatherservice/internal/adapters/httpserver 1.420s`.

The background query has a 30-second context timeout. The returned suggestion markup is rendered without waiting for that query. The source cache has no expiry; this warmup remembers successful destinations in memory and permits a later retry after an error.
