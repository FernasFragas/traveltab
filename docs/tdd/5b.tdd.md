# 5b — Name phrase and day-heading extraction

Source: `tasks/todo.md` 5b, `tasks/plan.md` index shape, and the PR 2 verdict in `tasks/writers-map-results.md`. Fixtures are synthetic HTML, not copied blog content.

## Journeys

- As the monthly sync, I want folded place-name candidates with exact positions so a later matcher can join them to Wikidata aliases without storing a post body.
- As the itinerary matcher, I want English and Portuguese day headings split into position ranges so place mentions can be assigned to the right day.
- As a reader of a listicle, I want numbered attractions kept as names without turning the post into an itinerary.

`ExtractPost(titleHTML, bodyHTML)` returns only phrases, day sections, and an itinerary flag. Each offset is a half-open Unicode rune span in the normalized plain-text stream: decoded HTML text, collapsed whitespace, newline at block boundaries, and one newline between a nonempty title and body. Inline tags add no separator. Each day starts at its heading and ends at the next day heading or the end of the stream. Capitalized sequences with connectors yield the full candidate and subspans up to five words. A lowercase-start word plus connector plus capitalized word is also indexed with `OriginalCase=false`; arbitrary lowercase prose is omitted.
