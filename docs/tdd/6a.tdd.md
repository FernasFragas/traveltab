# 6a — Matcher and itinerary assembly

Source: `tasks/todo.md` 6a; `tasks/plan.md` matching rules and the October 10 type-filter decision.

## Journeys

- As a traveler, I want only posts about my destination to count, so a same-name place in another city does not appear as a writer pin.
- As a traveler, I want aliases, casing, reviewed overrides and nested names resolved, so each pin represents the intended place once.
- As a traveler, I want writer pins ordered by distinct writers and writer routes ordered by first mention in each day.
