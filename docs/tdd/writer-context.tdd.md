# Writer post context — TDD and measurement

Source: [writer-context-plan.md](../../tasks/writer-context-plan.md) and C1–C4 in [writer-context-todo.md](../../tasks/writer-context-todo.md).

Journeys:
- As a traveller opening a Lisbon place, I want its posts to be about Lisbon, so that I do not read Madeira guides for a Lisbon parish.
- As a traveller opening a Madeira place, I want to keep the posts I get today, so that the fix does not empty the map.

## Method and choice

`launch-check.db` was copied to `/private/tmp/writer-context-launch.db`. Its only gazetteer cache was an obsolete Funchal v1 entry, so cached v3 Lisbon and Funchal gazetteers from another temporary app database were copied into the temp database. Porto had no local cache and was populated once by the app through its normal Wikidata source. The original `launch-check.db` was not edited. The measurement command decoded the index’s packed rune positions and replayed the old and candidate rules against these cached gazetteers. The 300-rune Porto output matched the live matcher exactly (4,873 positions, 722 posts, 214 pins before the overlapping-span correction); the final 1,000-rune counts below were checked against the live result for Lisbon and Funchal.

The index stores positions rather than post text. A fixed seed, `20261013`, selected 40 distinct mention positions from today’s rule per destination. The agent read all 98 distinct public pages with `internal/adapters/api.UserAgent`, then judged every sample using the title, place alias and public-page text. Windows below are short excerpts around a matching alias on the current public page; they may differ from the older indexed text. `right` means the post discusses the named place as part of the destination area, rather than using its name incidentally or for a namesake.

The actual `contextNames` implementation supplies **Lisbon** for a destination named Lisbon; it does not add Lisboa. This differs from the plan’s assumption that both forms are context names. Several genuine Lisboa-titled posts are consequently dropped at every W. The matcher’s context names were left as specified in the plan.

No W meets ≥90% precision and ≤10% recall loss in all three destinations. Per the plan’s fallback, **W=1,000** has the fewest judged right mentions dropped across all destinations (10, versus 11 at 600 and 12 at 300). The material gap is Lisbon’s 63.6% sample recall loss and low precision; Porto still loses 12.0% of right mentions. The selected rule is an improvement for the named Madeira false positive, but it does not meet the broader acceptance targets.
