- **Short stop description**: the plan's `planner.Place` carries no description, so none is shown. It needs a source (e.g. writers' summaries or Wikidata) and a planner/contract change.
- **`writers_pick` chip** (todo line 82, "Writers' pick") is not built: the planner does not set the flag yet.
- `distance_km` is computed in the view model from `planner.DistanceKM` (`stopLegs` in `trip.go`), not read from a planner field, because the plan stop type has no such field.
- The existing "Map export" (KML) link is kept next to the two requested buttons, because `TestPlanRoute_LinksToItsOwnExportsAndMapsRoutes` expects it.
- Styles for the new row elements are appended to `public/redesign/planner.css` (not in 7g's Owns; `map-saved.css` is for the saved line only).
- View on map uses an inline `onclick`, like the template's existing `onerror` handlers; no JS file is in 7g's Owns.
