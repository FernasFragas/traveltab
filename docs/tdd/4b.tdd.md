Source: `tasks/todo.md` 4b. The shared `BasePlaceSource` contract returns `writermap.BasePlaces` with both base pins and the unfiltered gazetteer.

## User journeys

- As a map visitor, I want a warm destination to load from SQLite so repeated views do not query Wikidata.
- As a map visitor, I want a cold lookup error to leave the layer empty and report the cause so the map can still load.
- As the monthly sync job, I want to refresh a destination and replace its cached row so later visitors see the new places.
- As visitors requesting the same destination together, we want one provider query so a burst does not multiply requests.
