## User journeys

- As a traveler, I want to pick how many people travel, so that the Booking link searches for the right group.
- As a traveler who shares a plan link, I want the number kept in it, so that others see the same search.
- As a visitor with a missing or odd value, I want the plan to still work with 2 travelers.
