# 7d — Save to plan: TDD Evidence

**Source task:** `tasks/todo.md` 7d (server side is 7e, not covered here). Files: `public/redesign/map-saved.js`, one script tag in `views/index.go.tpl`, `tasks/redesign/checks/map-saved.test.mjs`.

## User journeys

- As a traveler, I want to save places from the panel, so that I can plan around them later.
- As a returning traveler, I want my saves to survive a reload.
- As a traveler, I want the next plan to include my saved places, and to clear the list when I change my mind.
- As a privacy-restricted visitor (storage blocked), I want no broken buttons.
