# 7c — Writers' itinerary layers (browser)

Source: `tasks/todo.md` 7c. The data side is in [7c-itineraries-data.tdd.md](7c-itineraries-data.tdd.md).

## Journeys

- As a traveler, I want one writer's route drawn on the map as numbered pins and a line, so I can follow their trip.
- As a traveler, I want to pick between routes when several exist, and to turn the layer off with the "Writers' itineraries" chip.
- As a traveler, I want no empty chip or picker where nobody has published a route.

## Notes

- `writers-map.js` does not pass `itineraries` to layers, so the layer fetches the same GeoJSON URL once itself (cached per URL; the browser also caches it).
- The chip is hidden by `map-itineraries.css` unless the map shell has `data-itineraries`, so `map-layers.js` (7f) needed no change.
